# Contributing to Motion Superpowers

We welcome contributions of new motion style catalogs, shot recipes, and pipeline utilities.

## Guidelines

1. **Rulebook Quality**:
   - New `MOTION.md` catalogs must include: philosophy, duration tokens, easing curves, camera choreography rules, and anti-slop guidelines.
   - Ground values on real-world reference videos or established design systems.

2. **Clean Copy**:
   - Avoid marketing puffery and generic AI terminology.
   - Do not use emojis in code examples or markdown documentation.

3. **Deterministic Implementations**:
   - Component templates must be strictly frame-accurate and compatible with Remotion or HyperFrames.

## Submitting Pull Requests

1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/new-style-catalog`).
3. Commit your changes with clear, descriptive messages.
4. Push to the branch and open a Pull Request.
